# Redingenhof

Hierin worden een aantal applicaties ontwikkeld en onderhouden van GO! campus Redingenhof

Zo is er:

**RedingenhofID**.
Het doel van dit project is om bestaande, versnipperde tools  
(zoals Access-databases, PowerShell-scripts en andere losse scripts)  
te consolideren tot één geïntegreerde webapplicatie.

**Inktbeheer**.
Het doel van dit project is om het systeem op papier te digitaliseren.

Deze applicaties zullen zorgen voor betere onderhoudbaarheid, consistentie  
en gebruiksgemak binnen de organisatie.
